# Example canvases

- `schema-contracts.canvas` — model-delivery system with approved and overdue
  JSON Schema contracts, contract links, and deliberate consumer warnings.
- `order-erd.canvas` — minimal commerce ERD using Schema cards for `Customer`,
  `Order`, and `Order Item`, linked to `Commerce DB` and `Orders API`.
- `data-flow-contracts.canvas` — the model-delivery contract example arranged in
  Data flow mode, with runtime cards on the left and schemas in the right contract rail.

The `.canvas` examples use the Systems profile and Obsidian-compatible JSON Canvas.
Import them with **Import .canvas**.

- `simple-tasks-api.yaml` — OpenAPI 3.1 example for the API profile, with
  Tasks and Health resources, six endpoints, six schemas, and Bearer auth.
  Import it with **Import OpenAPI**.

- `model-delivery-migrated.canvas` — migrated copy of the Model Delivery canvas
  using Systems cards, JSON Schema contracts, data-flow layout, and preserved
  examples as Notes.
